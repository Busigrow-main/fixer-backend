Fixxer Shop API Documentation

Base URL: http://135.222.40.140/api/v1

All paths below are relative to that base. JSON request and response bodies. Dates are ISO-8601 strings.

1. Conventions

ItemRule
Auth headerAuthorization: Bearer <access_token>
Public routesNo token. Catalog browse and shop home.
Customer routesJWT required. Role CUSTOMER for part-help.
Admin routesJWT required. Role ADMIN.
Spare-part catalog pricePaise. 125000 means Rs 1,250.00
Shop home, cart, quote, invoice, appliance priceRupees
Error bodystatusCode, message, error

Error response

{
  "statusCode": 400,
  "message": "Cart is empty",
  "error": "Bad Request"
}

401 missing or bad token. 403 wrong role. 404 unknown id, SKU, or slug. 409 help request already moved.

11. Order status

StatusMeaning
PENDINGCreated, not yet processed
PROCESSINGAccepted / marked paid from PENDING
DISPATCHEDTracking saved
DELIVEREDComplete
CANCELLEDCustomer or admin cancel
RETURNEDReturned

paymentStatus: UNPAID | PAID. paymentMethod: COD | ONLINE.

15. End-to-end add flow

Browse shop home or catalog (public) → sign in with quick-login if needed → add to cart → GET installation/options for pincode → PATCH cart item with installationOptionId → POST cart/coupons → POST checkout/quote → POST checkout → GET user/part-orders/:id and tracking.

Alternate: POST /part-orders enquiry, or POST /shop/part-help then admin quote then customer accept.
